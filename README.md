# C.V.

Estensione browser Manifest V3 per Chromium (Chrome, Brave, Edge) e Firefox per l'amplificazione del volume fino al 500% e la regolazione della velocita video.

## Caratteristiche
- **Audio Boost**: amplificazione fino al 500% con limitatore audio.
- **Velocita Video**: controllo da 0.1x a 4x con preset rapidi, supporto per iframe e Shadow DOM.
- **Privacy**: elaborazione 100% locale in tempo reale; nessun dato raccolto o trasmesso.
- **Interfaccia**: supporto multilingua (IT, EN, ES, FR, DE) e tema chiaro/scuro automatico.

## Installazione
- **Chromium / Brave / Edge**: `chrome://extensions` -> attiva **Modalita sviluppatore** -> **Carica estensione non pacchettizzata**.
- **Firefox**: `about:debugging#/runtime/this-firefox` -> **Carica componente aggiuntivo temporaneo** -> seleziona `manifest.json`.
